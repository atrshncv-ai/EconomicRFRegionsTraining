# Предложения из аудита (источник R01)

Шесть предложений из отчёта прогона `func-audit`, принятые пользователем
словом «Давай добавим твои предложения» (брифинг прогона `extras`).

| # | Предложение (дословно из отчёта) | Цена из отчёта |
|---|----------------------------------|----------------|
| 1 | Слабые районы спрашивать чаще (прогресс по районам уже собирается) | малая |
| 2 | Клик по району в легенде в «Изучении» показывает список его субъектов | малая |
| 3 | Динамика по датам («было 40% → стало 80%») | средняя |
| 4 | Печатная версия состава районов для учителя | малая |
| 5 | Режим «соседи»: назвать регионы, граничащие с данным | большая (матрицу 89 соседств собирать вручную) |
| 6 | Контрастная тема для проектора | малая |
