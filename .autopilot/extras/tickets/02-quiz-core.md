## Критерии приёмки

- [ ] `weightFor(pct)` — вес выше при низком % (0% → макс, 100% → мин > 0); `buildRound` принимает веса и чаще берёт слабые районы (тест на сиде)

- [ ] Тест на шве покрывает каждую функцию, ожидаемые значения — вручную посчитанные, сид фиксирован
- [ ] `node --test` зелёный, старые тесты не сломаны
