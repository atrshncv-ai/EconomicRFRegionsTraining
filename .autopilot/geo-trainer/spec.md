# Спецификация: Геотренажёр экономических районов РФ

## Задача

Ученику (и учителю на доске) нужно выучить 12 экономических районов России и какие субъекты в каждый входят — сейчас это список текстом, по нему нельзя тренироваться. Нужна карта, где можно кликать и получать проверку, а не зубрить.

## Решение

Статическая веб-страница (только JS, без бэкенда) для заливки на z.ai: интерактивная SVG-карта России (основа — гитхаб alexTitakoff/svg-map-Russia + 4 дорисованных новых региона, итого 89), три режима (изучение, субъект→район, район→субъекты), счёт и работа над ошибками, прогресс в браузере, русские названия, легенда 12 районов.

## Решения по реализации

- Стек: статика HTML + CSS + vanilla JS (без сборки, без jQuery — почему: вес под z.ai 50 МБ и офлайн; jQuery из гитхаба выкидываем, оставляем SVG/идеи). Почему vanilla: z.ai принимает только лёгкие веб-языки.
- Основа карты: SVG из alexTitakoff/svg-map-Russia (85 контуров, id вида RU-MOW), переделанные id в единый формат; Крым (RU-CR) и Севастополь (RU-SEV) из него же. Почему: только там есть Крым из проверенных.
- Данные: `districts` (12: id, название, цвет, номер) + `subjects` (89: svgId, русское имя, districtId). Почему отдельная таблица: исходные name в SVG английские, а состав — по списку пользователя + ОКЭР.
- Новые 4 региона (ДНР, ЛНР, Запорожская, Херсонская): упрощённые полигоны поверх карты с пометкой «контур схематичный». Почему: в исходниках их нет (проверено: 83 и 85), а исключать их запретил пользователь.
- Логика викторины — чистые функции (вопрос → ответ → разбор), отдельно от DOM. Почему: единственный шов для тестов и переиспользование между тремя режимами.
- Прогресс: localStorage (счёт, % по 12 районам, очередь ошибок, состояние партии) + кнопка сброса; без localStorage — работа в памяти без падений. Почему: бэкенда нет по ограничению z.ai.
- Цвета 12 районов: фиксированная палитра + номер района; легенда всегда на экране. Почему: «только карта» + мелкие регионы требуют дублирующего кодирования.

Состав (заморожен, строго по списку + G04): Центральный 13; Центрально-Чернозёмный 5+ДНР+ЛНР=7; Северо-Западный 4; Северный 6; Калининградский 1; Волго-Вятский 5; Поволжский 8; Северо-Кавказский 12+Запорожская+Херсонская=14; Уральский 7; Западно-Сибирский 9; Восточно-Сибирский 6; Дальневосточный 9. Итого 89.

## Границы и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `data` | районы, субъекты, маппинг svgId→район | `getDistricts()`, `getSubjects()`, `districtOf(svgId)` | формат SVG, транслитерацию |
| `map` | отрисовка SVG, ховер, клики, зум/пан, подсветка | `highlight(ids, kind)`, `onPick(cb)`, `setZoom(level)` | DOM SVG, координаты |
| `quiz` | вопросы, проверка, счёт, очередь ошибок, подсказки | `nextQuestion(mode)`, `answer(q, a) -> {ok, correct}`, `retryQueue()` | хранение, отрисовку |
| `progress` | localStorage, сброс, восстановление партии | `load()`, `save(state)`, `reset()` | ключи storage, сериализацию |
| `ui` | экраны, легенда, теория, результаты | `show(screen, props)` | стили, тексты |

Швы для тестов: `quiz.answer` (чистая проверка) и валидация `data` (89 уникальных, покрытие 12 районов). Идеал — один: `quiz`, второй нужен только для целостности маппинга.
