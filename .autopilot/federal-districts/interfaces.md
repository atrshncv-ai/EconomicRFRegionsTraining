# Границы и правила сборки

## Границы, решённые в спецификации

- `data` — наборы ФО. `FO_GROUPS` (8: id, имя, аббревиатура, центр, centerNote, цвет), `FO_OF[svgId] = foId`
- `app` — активный набор. `setDataset(name)`; статистика/ошибки/история/веса раздельно (`eco`/`fo`)
- `ui` — переключатель набора, центр+счёт+типы в легенде
- Швы: валидация ФО-данных (89 ровно по одному, счётчики 18/11/12/7/14/6/10/11)

## Из таска 02 — движок на наборах

- `window.GEO_APP.setDataset/getDataset`; статистика eco/fo раздельно (asked/ok/errors/history/веса, кап истории на набор)
- Легенда ФО: имя+abbr+центр+счёт с разбивкой из названий; пометка 2018 у Владивостока

## Из таска 03 — печать обоих наборов

- Печать: оба состава, активный первым; центры+счётчики+разбивка+пометка 2018; карты-игры нет
- Smoke-хелпер `subjFromTitle()`: точное имя из заголовка (includes запрещён — NEN⊂YAN давал ~10% флаков)

## Из таска 01 — данные ФО

- `GEO_DATA.FO_GROUPS` (8, своя палитра), `FO_OF[svgId] = foId`; ЮФО 12 с новыми; `centerNote` у ДВФО

## Общие правила проекта

- Стек: статика HTML+CSS+vanilla JS, `python3 build.py` → `index.html` (всё инлайн, ≤50 МБ, без сервера, без внешних запросов)
- Тесты: `node --test tests/data.test.js tests/quiz.test.js tests/smoke.test.js`
- Составы обоих наборов зафиксированы тестами; `RU-VOR` — Воронежская (не «чинить»)
- Движок quiz/generic не ломать: функции принимают любые группы
- Не трогать: `vendor/map.svg`, `ru.svg`, `.autopilot/`, память проекта
- Не хватает зависимости — вернуть `BLOCKED`, из сети не ставить
